# Асети для Mission Architect

Оновлено: надані три JPG-аркуші та окрема драбина вже підключені до гри. Із них підготовлено 48 PNG: персонаж із ходьбою, ракета й ступені, лендер з опорами, вихлоп, хаб та станції, планети, супутники, місячні тайли, прапорці, значки, кнопки й логотип. Джерела лежать у `assets/source_sheets/`, результати — у `assets/art/`.

Для наступної заміни бажані оригінальні окремі PNG з прозорістю: JPEG містить підписи, сітку та втрати стискання, тому відновити всі початкові пікселі неможливо. Також ще потрібні звук, музика і повні анімації вихлопу, пилу та відділення. Таблиці нижче залишаються технічним контрактом для підготовки цих матеріалів.

## Спільні вимоги

- Виведення гри — **1920×1080**. Розміри нижче — логічні; підготовлені поточні PNG мають щільність ×3, а світ показується під масштабом ×6. Передавайте оригінальний розмір без збільшення, згладжування, розмиття й JPEG-стиснення.
- Спрайти й тайли: **PNG RGBA**, прозоре тло, sRGB. Вихідні `.aseprite` або `.kra` бажані додатково. Не вбудовувати тексти у зображення: мови UK/EN малюються окремо.
- Палітра спільна, **24–32 кольори**. Узгоджувані кольори ресурсів: маса `#9AA5B1`, енергія `#F2C94C`, бюджет `#4CAF50`, дані `#35B6E8`, зв’язок `#9B6BDE`, час `#F2994A`. Тимчасові фони: `#101A2B`, `#203147`, місячна порода `#566171`.
- Аркуші анімацій: одна дія на рядок, кадри зліва направо, однаковий розмір комірок, без trimming і поворотів. Додайте JSON/TXT із назвами дій, числом кадрів, FPS, loop, точкою прив’язки. За потреби залиште 1 px порожнього поля між комірками й зазначте це.
- Для всіх матеріалів потрібні автор, джерело й ліцензія або підтвердження права використовувати їх у грі. Графіку та звук Gravity Force не копіюємо.

## Як надіслати

Достатньо ZIP з папками `characters/`, `vehicles/`, `world/`, `ui/`, `audio/` та `licenses/`. Додайте `manifest.csv`: файл, автор, ліцензія, розмір кадру, число кадрів, FPS, loop, pivot_x, pivot_y. Розміри вище — контракт для підготовки, їх можна погодити перед малюванням. Підготовлені спрайти вже під’єднані до сцен. Заміна відповідного PNG в `assets/art/` оновить зображення після імпорту; для іншого розміру потрібно перевірити точку прив’язки й фізичний контур.
