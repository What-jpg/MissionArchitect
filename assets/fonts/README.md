# Fonts

UI font: **Tiny5** by The Tiny5 Project Authors (https://github.com/Gissio/font_tiny5),
Google Fonts: https://fonts.google.com/specimen/Tiny5 — SIL Open Font License 1.1 (Tiny5-OFL.txt).
Tiny5.ttf is the static default instance of the variable font with one added glyph (✗) drawn on the
font's own 128-unit pixel grid; it remains under the OFL.

Fallback font: MissionPixel.ttf, derived from Pixelify Sans by The Pixelify Sans Project Authors
(https://github.com/google/fonts/tree/main/ofl/pixelifysans) — SIL Open Font License 1.1 (PixelifySans-OFL.txt).

No other fonts are used.
